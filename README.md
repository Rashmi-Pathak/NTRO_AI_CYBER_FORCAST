## 🛡️ Overview

**NTRO AI CYBER FORECAST** is an advanced, military-grade cybersecurity dashboard built for the Smart India Hackathon. It leverages artificial intelligence to predict, analyze, and prevent cyber threats across critical government infrastructure. 

The platform transitions SOC analysts from reactive incident response to **proactive threat hunting**, predicting the next stages of an attack (e.g., Lateral Movement, Data Exfiltration) before they happen.

## ✨ Key Features

- **🌐 Live Threat Monitor**: Real-time global view of incoming threats with dynamic event tables and risk distribution charts.
- **🔮 Attack Forecast (AI)**: Predictive modeling that forecasts the next step of an attacker using the MITRE ATT&CK framework.
- **🗺️ Attack Path / Kill Chain**: Visual representation of the attack lifecycle, from initial compromise to predicted targets, including blast radius calculations.
- **🎯 Target & Asset Intelligence**: Comprehensive inventory of critical assets, mapped against real-time vulnerabilities.
- **🏭 Sector Intelligence**: Macro-level view of threats targeting specific sectors (Government, Finance, Power & Energy).
- **🚨 Incident Management**: End-to-end incident response tracking, severity mapping, and containment workflows.
- **🧠 Model Intelligence**: Monitor the health, accuracy, and drift of the underlying AI/ML models powering the predictions.
- **🧪 Data & Simulation Lab**: Run synthetic attacks (e.g., Ransomware outbreaks, DDoS) in a safe environment to test infrastructure resilience.

## 💻 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Rashmi-Pathak/NTRO_AI_CYBER_FORCAST.git
   cd NTRO_AI_CYBER_FORCAST/frontend
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open your browser:**  
   Navigate to `http://localhost:3000` to view the application.

## 🎨 UI/UX Philosophy

The interface is designed specifically for high-stress Security Operations Centers (SOCs). 
- **Dark Theme Default**: Deep navy `#020813` reduces eye strain during long shifts.
- **High Contrast Accents**: Electric blue (`#00a3ff`), critical red (`#ff3b30`), and amber (`#ff9500`) are used sparingly to draw attention only to what matters.
- **Information Density**: High data density without clutter, utilizing typography and subtle glass panels (`backdrop-blur`) to separate information hierarchies.
